<h2 id="tutorial_summary">Summary</h2>

This tutorial guided you through the basic SimVascular workflow for creating a model, generating a mesh, running a CFD simulation,
and inspecting the results.

The SimVascular <i>User Guides</i> and <i>Clinical Cases</i> provide more detailed information about the
topics covered in this <i>Tutorial</i>.

The <a href="https://www.youtube.com/playlist?list=PL1CBZ8Wh-xvSKUsuBA4MM4Jba-psVdxXT">SimVascular Online Tutorials</a> video series
provides demonstrations by experienced users building models and setting up simulations for different applications.

The <a href="https://simtk.org/plugins/phpBB/indexPhpbb.php?group_id=188&pluginname=phpBB">SimVascular Forum</a> is an additional
resource for seeking answers to specific questions. Searching the <i>Forum</i> can be helpful for finding tips and solutions
related to SimVascular quirks and limitations.

Functionality not supported by the SimVascular GUI may be implemented using the <a href="python_interface.html">Python API</a>.
