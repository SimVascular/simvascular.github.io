## Installation

An installer containing the svZeroDSolver C++ executable and shared library can be download from [SimTK Simvascular Downloads](https://simtk.org/frs/?group_id=188). 

### Using pip

The Python wrapped svZeroDSolver can installed from PyPi using 
```
pip install svzerod
```

### Installing from GitHub 
The <b>svzerod</b> can be installed as a local package from the GitHub repository using 
```bash
git clone https://github.com/simvascular/svZeroDSolver.git
cd svZeroDSolver
pip install -e .
```
